# 발표용 자료

발표 중에는 통합 대본 하나를 열어 둔다. 화면 조작 지시 바로 뒤에 해당 화면에서 할 말을 붙이고, 확인 질문과 다음 장 연결까지 같은 순서로 읽는다.

- [AWS 확장판 PPT 48장](스터디예약_AWS확장판.pptx): 기본 코드 투어 42장 + AWS 범위·배포 비교·사람과 CI 인증·비용 설명 6장
- [큰 글씨 통합 발표 대본](스터디예약_통합발표대본.docx): 본문 14.5pt, 질문 답변 14pt. 48장 대본과 96개 Q&A를 문서 안에서 왕복 이동
- [GitHub에서 같은 대본 읽기](발표진행대본.md): 같은 화면 지시·대사·질문·연결 멘트와 실제 파일 링크
- [짧은 진행 큐시트](../presenter-guide.md): 사전 준비·60분과 75분 시간표·현장 화면 전환
- [슬라이드별 실제 파일 지도](../slides-map.json): PPT 각 장의 파일·앵커·명령·기대 결과
- [AWS 로그인과 배포 방식 및 비용](../aws-login.md): 실제 계정 작업 전 읽을 상세 설명

기본은 60분 또는 75분이며 AWS 43–48장을 더하면 20분을 추가한다. 발표 전에 `./dev up` → `./dev verify` → `./dev status`를 순서대로 실행한다. 현장에서는 4·42장의 status 확인을 기본으로 하고, 긴 검사는 사전 결과를 설명한다.

현재 범위는 로컬 실행·검사와 AWS 코드의 정적 검사까지다. 실제 AWS 로그인·plan·apply·ECR push·운영 배포, 원격 GitHub Actions 실행은 하지 않았다. 기존 대본에 표시된 명령은 통합 대본의 현장·사전·선택 구분을 따라 읽는다.
